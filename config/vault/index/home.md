# 我的知识库

从这里开始：[[wiki/getting-started|使用指南]] · [[index/topics|主题导航]] · [[raw/inbox|待整理素材]] · [[outputs/review-log|整理记录]]

## 三步使用
1. 把网页摘录、阅读笔记放到 `raw/web/` 或 `raw/notes/`，保留来源和日期。
2. 让 AI 提取观点、证据和疑问，写入 `wiki/`，并回链原始素材。
3. 更新 [[index/topics]]；回答有价值时保存到 `outputs/`。

## 可以直接提出的请求
- “整理 raw/ 中尚未编译的素材，生成知识条目并更新主题索引。”
- “基于知识库回答我的问题，每个关键结论注明来源；资料不足时明确说明。”
- “检查知识库的断链、重复条目和相互矛盾的观点，先给出处理建议。”
